# RIP-7212 Research

## Status

- RIP-7212 status: **Final** (CONFIRMED)
- Scope: precompile for secp256r1 signature verification (CONFIRMED)

Source: `ethereum/RIPs` `RIPS/rip-7212.md`.

## Interface

- Mechanism: precompiled contract `P256VERIFY` (CONFIRMED)
- Address: `0x0000000000000000000000000000000000000100` / `0x100` (CONFIRMED)
- Input: exactly 5 x 32-byte fields = 160 bytes (CONFIRMED)
  - `hash` (32)
  - `r` (32)
  - `s` (32)
  - `x` (32)
  - `y` (32)
- Encoding: big-endian integers (CONFIRMED)
- Output on success: 32-byte word with value `1` (CONFIRMED)
- Output on failure: empty return data (CONFIRMED)

## Curve parameters

RIP-7212 defines secp256r1 parameters (`p`, `a`, `b`, `G`, `n`, `h`) and validation requirements for `(r,s)` and `(x,y)`.

## Gas behavior

- RIP-7212 gas cost: `3450` (CONFIRMED in RIP-7212)

## Invalid-input behavior

RIP-7212 requires rejecting out-of-range signature components and invalid/off-curve public keys. Failure semantics are empty return data.

## Compatibility notes

- Base introduced this precompile during Fjord (CONFIRMED from Base docs).
- Ethereum L1 later standardized compatible precompile interface via EIP-7951 with 6900 gas (CONFIRMED from Base docs + EIP-7951).
