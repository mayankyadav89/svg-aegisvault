# Security Policy

## Experimental status

AegisVault is in a protocol-verification research phase and is **not production-ready**.

## Safe-use policy

- Do not use production funds.
- Do not use real private keys or seed phrases in research artifacts.

## Reporting a vulnerability

Please report security issues privately using GitHub Security Advisories for this repository ("Report a vulnerability" in the Security tab).

If private reporting is unavailable, open a GitHub issue using `.github/ISSUE_TEMPLATE/security.md` without publishing exploit-sensitive details.
